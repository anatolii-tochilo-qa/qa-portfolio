# Test Plan — SauceDemo

## 1. Test Objectives

The objective of this testing project is to evaluate the functionality and usability of the SauceDemo web application and identify potential defects.

The main goals are:
- Verify user authentication.
- Validate product catalog functionality.
- Check shopping cart operations.
- Verify the checkout process.
- Identify functional and UI defects.

## 2. Scope of Testing

### In Scope
- Login and logout functionality.
- Product catalog.
- Product sorting.
- Adding and removing products from the cart.
- Shopping cart functionality.
- Checkout form validation.
- Order completion.

### Out of Scope
- Backend source code testing.
- Performance and load testing.
- Security penetration testing.
- Real payment processing.

## 3. Test Approach

Testing will be performed manually using the following techniques:

- Positive Testing.
- Negative Testing.
- Boundary Value Analysis.
- Equivalence Partitioning.
- Exploratory Testing.
- Functional Testing.
- UI Testing.

## 4. Test Environment

- Application: https://www.saucedemo.com/
- Operating System: To be recorded.
- Browser: To be recorded.
- Testing Type: Manual Testing.

## 5. Test Deliverables

- Test Plan.
- Test Checklist.
- Test Cases.
- Bug Reports.
- Test Execution Results.
- Test Summary Report.

## 6. Entry Criteria

- Application is accessible.
- Test environment is available.
- Testing scope is defined.

## 7. Exit Criteria

- All planned test cases have been executed.
- Test results have been documented.
- Identified defects have been reported.
- Test Summary Report has been prepared.

## 8. Risks and Limitations

- Application availability may affect test execution.
- Demo application behavior may differ from production systems.
- Some application features may be intentionally designed to demonstrate defects.
